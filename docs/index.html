Botões (build 2)

BotãoGPIOFunção
A34SELECT / OK
B35NEXT / UP

Atenção: GPIO34 e 35 são só entrada e não têm pull-up/pull-down interno, então INPUT_PULLDOWN não funciona. Use pull-up externo de 10k para 3.3V (LOW = apertado) ou mude para GPIO32/33 com INPUT_PULLUP.

Lição aprendida: a tela é 240×240. O primeiro layout supôs 320px e teve que ser refeito.
